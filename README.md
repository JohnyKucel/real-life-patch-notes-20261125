One line, 145 characters: a software patch note for a bug in human biology — **v1.9.3: fixed a bug where the brain replayed your most embarrassing moment from 2009 at 3 a.m. instead of sleeping. Known issue: replay is in HD.**

The program writes that line to `entry.txt`, gated to the competition's rules (UTF-8, 1–160 characters, single line, not whitespace-only), so the entry is valid before it ever reaches the judge.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/patch-notes-output python3 main.py
```

Writes the patch note to `entry.txt` in the output directory (or `output/` when `MAKEFUN_OUTPUT_DIR` is unset). Python 3.13, standard library only, deterministic — no network, no randomness, no clock.
